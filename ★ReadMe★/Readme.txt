★操作方法

[キーボード操作]
　移動				：方向キー
　決定				：z、ENTER、スペース
　キャンセル、メニュー		：x、Esc
　ダッシュ			：SHIFT
　メッセージ非表示		：CTRL
　メッセージスキップ		：x、Esc
　装備画面キャラ切り替え	：左右キー、PageUp/PageDown


[マウス操作]
　移動				：左クリック
　決定				：左クリック
　キャンセル、メニュー		：右クリック
　ダッシュ			：SHIFT

[ゲームパッド]
　移動				：十字キー
　決定				：A
　キャンセル			：B
　ダッシュ			：X
　メニュー			：Y
　メッセージスキップ		：Y
　装備画面キャラ切り替え	：左右キー
